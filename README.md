# Stellar Burgers 🍔

Веб-приложение для создания и заказа космических бургеров.

## 📋 О проекте

Stellar Burgers — это SPA-приложение, которое позволяет пользователям:
- Конструировать бургеры из различных ингредиентов
- Оформлять и отслеживать заказы
- Просматривать ленту всех заказов в реальном времени
- Управлять профилем и историей заказов

## 🚀 Технологический стек

### Основные технологии
- **React 18** — библиотека для построения пользовательских интерфейсов
- **TypeScript** — типизированный JavaScript для повышения надежности кода
- **Redux Toolkit** — управление состоянием приложения
- **React Router v6** — навигация и маршрутизация
- **Webpack 5** — сборка приложения

### Дополнительные инструменты
- **Jest** — unit-тестирование
- **Cypress** — E2E-тестирование
- **Storybook** — разработка и документирование UI-компонентов
- **ESLint & Prettier** — линтинг и форматирование кода

## 🎯 Основные возможности

### Конструктор бургеров
- Drag & drop интерфейс для добавления ингредиентов
- Динамический расчет стоимости заказа
- Перемещение и удаление ингредиентов

### Система заказов
- Оформление заказа с авторизацией
- Просмотр деталей заказа
- Лента всех заказов в реальном времени
- История личных заказов

### Авторизация
- Регистрация и вход пользователей
- Защищенные маршруты
- Восстановление пароля
- Обновление профиля

### Навигация
- Модальные окна с поддержкой роутинга
- Детальная информация об ингредиентах
- Сохранение состояния при переходах

## 📦 Установка и запуск

### Требования
- Node.js >= 16.x
- npm >= 8.x

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm start
```

### Сборка production-версии
```bash
npm run build
```

## 🧪 Тестирование

### Unit-тесты (Jest)
```bash

```

Покрытие тестами:
- Redux слайсы (reducers, actions, selectors)

### E2E-тесты (Cypress)

Тестовые сценарии:

## 🏛️ Архитектурные решения

### Управление состоянием
- **Redux Toolkit** для глобального состояния
- Typed хуки `useDispatch` и `useSelector`
- Разделение логики по feature-слайсам
- Асинхронные действия через `createAsyncThunk`

### API-интеграция
- Централизованный API-клиент в `burger-api.ts`
- Автоматическое обновление JWT-токенов
- Обработка ошибок и загрузочных состояний
- Cookie и localStorage для хранения токенов

### Типизация
- Строгая типизация всех компонентов и функций
- Type-safe Redux store
- Интерфейсы для API-ответов
- Enum-подобные типы для статусов

### Роутинг
- Защищенные маршруты для авторизованных пользователей
- Модальные окна через state роутера
- Сохранение фонового контента при открытии модалок
